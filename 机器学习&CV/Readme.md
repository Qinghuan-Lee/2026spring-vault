**k近邻算法(k-NN)** 的艺术在于选择合适的k值  不合适的k会发生过拟合或者欠拟合 

**支持向量机 SVM(support vector machine)** 
svm会选择让两个类别之间距离尽可能大的线 这个距离叫做间隔 
最靠近边界的点叫做支持向量  一旦边界被找到 就只有这些支持向量对定义边界起作用  即使其他数据丢失 边界也保持不变  这使得svm既省内存又很优雅
当数据不是线性可分的时候  引入核函数kernel 它让svm在处理非线性问题时非常强大

**朴素贝叶斯算法**是一种基于概率和贝叶斯定理的分类算法

**决策树(Decision Tree)** 是最直观的机器学习算法之一
