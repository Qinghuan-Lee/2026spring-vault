**项目推荐**

- [Spring AI Alibaba DataAgent](https://github.com/spring-ai-alibaba/DataAgent) [Java]🌟🌟🌟🌟🌟
    
    - 评价：这是一个企业级智能数据分析 Agent，很多公司都在做传统的 Text2SQL、NL2Chart，这种项目的应用范围很广，非常推荐学习，很适合找工作
        
- [Learn-Claude-Code](https://github.com/shareAI-lab/learn-claude-code/blob/main/README-zh.md) [Python] 🌟🌟🌟🌟🌟
    
    - 评价：这个项目我很喜欢，是一个从 0 到 1 的学习项目，带你从 0 构建一个 mini 版ClaudeCode
        
- [企业级 AI 工作流可视化编排平台](https://github.com/itwanger/PaiAgent) [Java SpringAI] 🌟🌟🌟🌟
    
    - 评价：这个项目很多公司都有使用场景，我相信绝大多数业务场景都在用AI工作流，大厂最爱造轮子，所以这种基建产品肯定需要需要开发。
        
- [基于 Skill 检索的RAG 系统](https://github.com/lyxhnu/Skill-First-Hybrid-RAG) [Python] 🌟🌟🌟
    
    - 评价：使用 LangGraph 编排全过程，用 Skill 做文件级路由，这个项目比较新颖，不是完全基于 Embedding 那套策略的
